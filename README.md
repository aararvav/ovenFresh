
# ovenFresh

OvenFresh is a modern, responsive food ordering website designed for the restraunt chain. It allows users to explore the menu, sign up or log in, add items to a cart, and place orders seamlessly.
## Features

Responsive design for all screen sizes

User authentication (Login/Register)

Password visibility toggle and validation

Add-to-cart functionality with real-time updates

Interactive product cards

Local storage-based cart management

## Tech Stack

HTML5

CSS3

JavaScript (Vanilla)

## Run Locally

Clone the project

```bash
  git clone https://github.com/aararvav/ovenFresh
```

Go to the project directory

```bash
  cd ovenFresh
```
## Documentation

**The main components are:**

**index.html**: Homepage and layout

**login.html**: Login and Register forms

**style.css**: All styles and responsiveness

**script.js**: Functionality (password toggle, cart, validations)
